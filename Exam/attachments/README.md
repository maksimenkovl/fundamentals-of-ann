# Вложения зачётного блока

Итоговая зачётная работа выполняется письменно по билетам, формируемым из банков вопросов ([`resources/test-banks/`](../../resources/test-banks/README.md)), поэтому стартовый ноутбук для неё не предусмотрен.

Практическая часть подготовки к зачёту опирается на материалы модулей: стартовые ноутбуки ПР 1–10 и кейсов — в `attachments/` каталогов `M1-fundamentals-of-ann/`, `M2-complex-models/`, `Project/`.
